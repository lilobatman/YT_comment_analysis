# YT_comment_analysis
Das Projekt untersucht, wie Menschen in den Kommentaren unter einem YouTube-Video über dieses Video denken, also ob die Stimmung eher positiv, negativ oder neutral ist.  Dazu holt es automatisch bis zu 1.000 Kommentare von einem Video, bereinigt die Texte und lässt ein Programm für jeden Kommentar bewerten, wie positiv oder negativ er klingt
